\section{Evidence boundary and reproducibility objects}

This supplement reports the complete registered P1 definitions and the negative evidence needed to interpret the main article. It does not add a geotechnical validation problem, mesh or time-step convergence, native balance closure, or a full-domain result. The public v0.8.2 artifact at \url{https://github.com/yqma7980/rollback-consistent-multiphase-uel-verification}, archived under \href{https://doi.org/10.5281/zenodo.21773371}{10.5281/zenodo.21773371}, contains the frozen UEL and standalone harness, input state and direction manifests, preregistrations, complete CSV evidence used in all figures, plotting scripts, and SHA-256 manifests. Code uses the MIT License; data, documentation, figures, and manuscript-supporting material use Creative Commons Attribution 4.0 International.

The global sign convention is
\begin{equation}
\mathrm{RHS}=-\mathbf{R},\qquad
D(\mathrm{RHS})[\mathbf d]\simeq-\mathbf J_{phys}\mathbf d.
\end{equation}
The host receives $\mathbf J_{returned}$, while the registered physical-derivative test removes the unpaired matrix guard. No block, state, direction, or perturbation level selects an independent sign.

The four-node element is plane strain, uses $2\times2$ Gauss integration and unit thickness in the P1 tests, and orders each node as $(u_x,u_y,p_w,S_n)$. The implemented closures are
\begin{align}
S_w&=1-S_n,\quad
S_e=\operatorname{clip}\!\left(\frac{S_w-S_{wr}}{1-S_{wr}-S_{nr}};\varepsilon,1-\varepsilon\right),\\
p_c&=p_b(S_e^{-1/\lambda_{BC}}-1),\quad
k_{rw}=S_e^{n_w},\quad k_{rn}=(1-S_e)^{n_n},\\
p_{eq}&=p_w+(1-S_e)p_c,\\
K_{raw}&=K_0e^{a_\sigma(\sigma'_m-\sigma'_0)}s_{cb},\\
s_{cb}&=1+a_{cb}(CB_{GP}-CB_0),\\
K&=\operatorname{clip}(K_{raw};K_{min},K_{max}).
\end{align}
They are frozen engineering choices, not a thermodynamic derivation or project calibration.

\subsection{Weak residuals and nine-block derivative ledger}

With current trial superscript $k$ and committed beginning-state superscript $n$,
\begin{align}
\mathbf R_u &= \int B^T\boldsymbol\sigma'\,d\Omega
-\int B^T\alpha p_{eq}\mathbf m\,d\Omega,\\
R_{p,i} &= \int\!\Bigg[
N_i c_{p,\mathrm{impl}}\frac{p_w^k-p_w^n}{\Delta t}
+N_i\alpha\frac{\varepsilon_v^k-\varepsilon_v^n}{\Delta t}\notag\\
&\hspace{35mm}+\nabla N_i\!\cdot(\lambda_w\nabla p_w^k)\Bigg]d\Omega,\\
R_{s,i} &= \int\!\Bigg[
N_i\phi\rho_n\frac{S_n^{use}-S_n^n}{\Delta t}
+N_i\rho_n\beta_\phi S_n^{use}
\frac{\varepsilon_v^k-\varepsilon_v^n}{\Delta t}\notag\\
&\hspace{20mm}+\nabla N_i\!\cdot\Big\{\lambda_n
[\nabla p_w^k+p_c'(S_n^k)\nabla S_n^k]\Big\}\Bigg]d\Omega.
\end{align}
where $\lambda_w=Kk_{rw}/\mu_w$ and $\lambda_n=\rho_nKk_{rn}/\mu_n$. RP is a wetting pressure-storage/volumetric balance and RS is a non-wetting mass balance; their native units differ and direct summation is forbidden.

The source initializes slots 15--48 to zero on each candidate rebuild, then conditionally overwrites slots 15--32 under the mechanics-debug gate and slots 33--45 under the output-source gate. Static source tracing found no use of slots 15--45 in \texttt{RHS}, \texttt{AMATRX}, or the construction of slots 1--14; the machine-readable audit records every read/write anchor. This establishes a static no-reverse-physical-path result, not universal dynamic noninterference. The repair stores CAP\_REF and CAP\_REF\_VALID in slots 13--14. A candidate may be returned during a trial, but no private user-memory commit is authoritative. The tested contract is:
\begin{enumerate}
\item equal declared state after clean and permuted rejected histories;
\item clean versus forced-cutback accepted path;
\item zero-increment and terminal-call noninterference;
\item output-on/output-off physical-state parity;
\item independent-process replay and restart where registered.
\end{enumerate}
Only these paths are covered; all-state and all-host-path safety are not claimed.

\section{Reproducibility-package layout}

The v0.8 review package is self-contained for figure reconstruction and organized as follows:
\begin{itemize}
\item \path{src/}: frozen verified UEL and standalone integrated finite-difference harness;
\item \path{inputs/}: exact state, direction, branch, constraint, and benchmark manifests;
\item \path{evidence/}: every CSV consumed by the figure builders, including the seven inputs omitted from v0.7;
\item \path{preregistration/}: the principal frozen protocols;
\item \path{scripts/}: package-relative main/supplementary figure builders and an isolated smoke test;
\item \path{host_evidence/}: available repaired-build WP08 decks, launcher logs, parsed host outputs, and audits;
\item \path{scripts/}: package-relative main and supplementary figure builders plus the clean-room smoke test;
\item \path{MANIFEST_SHA256.csv}: relative path, byte count, and SHA-256 for every distributed object.
\end{itemize}

The figure-rebuild smoke test is executed from a fresh directory with no reference to the author workspace and checks all 54 PDF/SVG/PNG figure outputs against expected hashes. The package does not include Abaqus executables or licensed solver binaries, and the available WP08 host archive lacks the unsafe source and original \texttt{.sta/.msg/.dat} triplet needed for a complete before/after host replay. The public identifiers and licenses improve inspectability but do not upgrade the bounded lifecycle, derivative, convergence, conservation, or engineering-qualification claims.
